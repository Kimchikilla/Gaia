# Gaia 문서 인덱스

`docs`는 사람이 읽는 Markdown 문서만 둔다. JSON 결과, 그림, 논문 PDF/TEX는 `artifacts/` 또는 `manuscripts/`에 둔다.

## 핵심 문서

| 위치 | 내용 |
|---|---|
| `../ROADMAP.md` | 현재 프로젝트 로드맵 |
| `standards/data_standard.md` | 토양 미생물 데이터 표준 |
| `standards/prescription_auto_recommendation_data_criteria.md` | 처방 자동 추천 자체 데이터와 평가 기준 |
| `reports/soil_state_evaluation_summary.md` | 토양 상태 진단 honest evaluation 요약 |
| `reports/public_soil_data_collection_summary.md` | 공개 토양 데이터 수집 현황 |
| `reports/public_soil_model_training_summary.md` | 공개데이터 baseline 학습 결과 |
| `reports/benchmark_validation_summary.md` | 진단 benchmark 검증 요약 |
| `reports/field_validation_literature_review.md` | 현장 검증 관련 문헌 검토 |
| `logs/` | 과거 학습/실험 로그 |
